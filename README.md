One line roasting the AI agent its own maker built, for the make.fun
bounty "Roast Your Own Agent" ($5, free entry).

`main.py` scores a handful of candidate roasts against the house judge's
own five criteria, in the order the judge weighs them, and writes the
winner to `/output/entry.txt`:

> My agent treats every $5 bounty like a lottery ticket and my patience like an infinite resource.

Run it with Python 3.13 (stdlib only, no dependencies):

```
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
